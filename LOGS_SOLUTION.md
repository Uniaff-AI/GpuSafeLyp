# 📋 Решение проблемы с логами в ComfyUI

## ❌ Проблема:
Логи не отображаются в интерфейсе балансировщика из-за проблем с WebSocket проксированием.

## ✅ Решение:

### 🎯 Основной рабочий процесс:

1. **Отправка задач (автораспределение):**
   ```
   http://89.208.11.177:8190
   ```
   - Используйте для отправки всех задач
   - Автоматическое распределение по GPU работает
   - Задачи идут на наименее загруженный GPU

2. **Мониторинг логов:**
   ```
   http://89.208.11.177:8188  (GPU 0 - логи в реальном времени)
   http://89.208.11.177:8189  (GPU 1 - логи в реальном времени)
   ```

### 💡 Рекомендуемая стратегия:

#### Вариант A: Две вкладки браузера
1. **Вкладка 1**: http://89.208.11.177:8190 (отправка задач)
2. **Вкладка 2**: http://89.208.11.177:8188 (мониторинг логов)

#### Вариант B: Терминальный мониторинг
```bash
# В отдельных терминалах:
tail -f ~/ComfyUI/ComfyUI_main/comfyui_gpu0.log
tail -f ~/ComfyUI/ComfyUI_main/comfyui_gpu1.log
tail -f ~/ComfyUI/ComfyUI_main/smart_balancer.log
```

#### Вариант C: GPU мониторинг
```bash
watch -n 2 nvidia-smi
```

### 📊 Как работает автораспределение:

1. **Отправляете задачу через порт 8190**
2. **Балансировщик выбирает** наименее загруженный GPU:
   - GPU 0 свободен → задача на GPU 0
   - GPU 1 свободен → задача на GPU 1
   - Оба заняты → очередь к менее загруженному

3. **Мониторите выполнение** через прямые порты или терминал

### ✅ Проверка работы:

#### Проверить автораспределение:
```bash
# Статус через балансировщик
curl -s http://localhost:8190/queue | jq '{running: (.queue_running | length), pending: (.queue_pending | length)}'

# Статус GPU напрямую
curl -s http://localhost:8188/queue | jq '{running: (.queue_running | length), pending: (.queue_pending | length)}'
curl -s http://localhost:8189/queue | jq '{running: (.queue_running | length), pending: (.queue_pending | length)}'
```

#### Проверить нагрузку GPU:
```bash
nvidia-smi --query-gpu=index,memory.used,utilization.gpu --format=csv,noheader,nounits
```

### 🎯 Тестирование параллельной обработки:

1. **Отправьте первую задачу** через http://89.208.11.177:8190
2. **Сразу отправьте вторую** через тот же порт
3. **Проверьте** - должны обрабатываться на разных GPU:
   ```bash
   nvidia-smi  # Оба GPU должны быть нагружены
   ```

### 🔧 Устранение неполадок:

#### Если задачи не распределяются:
```bash
# Перезапуск балансировщика
pkill -f smart_load_balancer
cd ~/ComfyUI/ComfyUI_main
conda activate latentsync
nohup python smart_load_balancer.py > smart_balancer.log 2>&1 &
```

#### Если нужны логи в балансировщике:
Временно используйте прямые порты 8188/8189 для мониторинга.
