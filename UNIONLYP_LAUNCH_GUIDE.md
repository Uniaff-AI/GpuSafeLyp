# 🚀 UNIONLYP LAUNCH GUIDE v2.0

## Новые возможности в версии 2.0:

✨ **Автоматическая синхронизация очередей backend ↔ ComfyUI**
- Каждые 30 секунд система проверяет соответствие задач
- Автоматически удаляет зависшие задачи (>8 мин без активности GPU)

- Полная проверка прав доступа к файлам
- Мониторинг процессов ComfyUI по всем GPU

✨ **Случайные seed-значения для уникальных результатов**
- Каждая задача использует случайный seed (1-999999)
- Исключает дублирование результатов

## 🔍 СИСТЕМА АВТОМАТИЧЕСКОЙ СИНХРОНИЗАЦИИ

### Как работает sync check:

1. **Каждые 30 секунд** система проверяет все активные задачи в backend
2. **Для задач старше 8 минут** проверяет:
   - Загрузку GPU через nvidia-smi
   - Наличие задач в очереди ComfyUI
3. **Если GPU < 10% и очереди нет** - задача считается зависшей
4. **Автоматически удаляет** зависшие задачи и логирует это

### Защита от OOM:

- Мониторинг VRAM через nvidia-smi
- Автоматическая очистка памяти при >95% использования
- Временное исключение серверов из балансировки после OOM
- Автоматический перезапуск при критических ошибках (5+ подряд)

## 🛠️ ДИАГНОСТИЧЕСКИЕ ИНСТРУМЕНТЫ

## ⚡ ОПТИМИЗАЦИИ В ВЕРСИИ 2.0

## 🎬 СТАТИСТИКА ИСПОЛЬЗОВАНИЯ

Backend теперь сохраняет seed для каждой задачи. Проверить:

```bash
curl http://localhost:8000/queue/status | jq '.queue[] | {task_id: .task_id, seed: .seed, status: .status}'
```

Пример ответа:
```json
{
  "task_id": "abc-123",
  "seed": 456789,
  "status": "completed"
}
```
