# 🎬 unionlyp - Advanced LipSync AI System

## 📋 Обзор проекта
Профессиональная система для генерации видео с синхронизацией губ на базе LatentSync с поддержкой 8 GPU серверов, smart балансировкой нагрузки и полной защитой от сбоев.

---

## 🎯 Основные возможности

### 🎬 **Генерация LipSync видео**
- Высококачественная синхронизация губ с аудио
- Поддержка различных форматов видео и аудио
- Настраиваемые параметры качества (inference_steps: 8, lips_expression: 1.5)
- Автоматическая подгонка длины видео под аудио

### 🚀 **Производительность и масштабируемость**
- **8 параллельных GPU серверов** (CUDA 0-7)
- Одновременная обработка до 8 задач
- Автоматическое распределение нагрузки
- Поддержка очередей задач

### 🎲 **Уникальность результатов**
- Автоматическая генерация случайных seed (1-999999)
- Каждая задача получает уникальный результат
- Логирование и сохранение использованных seed
