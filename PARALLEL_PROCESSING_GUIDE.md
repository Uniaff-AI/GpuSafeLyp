# 🚀 ComfyUI Dual GPU - Параллельная обработка через веб-интерфейс

## 🎯 Как использовать два GPU параллельно:

### Способ 1: Умный селектор (РЕКОМЕНДУЕТСЯ)
**Откройте:** http://89.208.11.177:8191/comfyui_selector.html

Этот интерфейс показывает статус обеих GPU в реальном времени и позволяет выбрать наименее загруженную.

### Способ 2: Прямой доступ (для опытных пользователей)
1. **GPU 0:** http://89.208.11.177:8188
2. **GPU 1:** http://89.208.11.177:8189

## 📋 Процесс параллельной обработки:

### 🖥️ Через умный селектор:
1. Откройте http://89.208.11.177:8191/comfyui_selector.html
2. Посмотрите статус GPU (🟢 свободен / 🔴 занят)
3. Кликните "Открыть ComfyUI" на свободном GPU
4. Для второй задачи повторите процесс - выберите другой свободный GPU

### 🔄 Через прямые ссылки:
1. **Первая задача:** Откройте http://89.208.11.177:8188
   - Загрузите воркфлоу
   - Загрузите видео и аудио
   - Запустите обработку

2. **Вторая задача:** В новой вкладке откройте http://89.208.11.177:8189  
   - Загрузите тот же воркфлоу
   - Загрузите другие видео и аудио
   - Запустите обработку

**Результат:** Обе задачи обрабатываются одновременно на разных GPU! 🎉

## 📊 Мониторинг параллельной обработки:

### В терминале:
```bash
# Мониторинг GPU
watch -n 1 nvidia-smi

# Проверка очередей
curl -s http://localhost:8188/queue | jq '{running: (.queue_running | length), pending: (.queue_pending | length)}'
curl -s http://localhost:8189/queue | jq '{running: (.queue_running | length), pending: (.queue_pending | length)}'
```

### Через веб-интерфейс:
- Селектор автоматически обновляется каждые 5 секунд
- Показывает количество задач в работе и в очереди
- Индикаторы состояния: 🟢 свободен, 🔴 занят

## ⚡ Производительность:

**До (1 GPU):**
- 1 задача → 2-3 минуты
- 2 задачи → 4-6 минут (последовательно)

**После (2 GPU):**
- 1 задача → 2-3 минуты  
- 2 задачи → 2-3 минуты (параллельно)

**Ускорение: до 2x для множественных задач!** 🚀

## 🔧 Управление системой:

### Запуск всей системы:
```bash
cd ~/ComfyUI/ComfyUI_main
./run_comfyui_dual_gpu.sh        # Запустить два ComfyUI
python serve_selector.py         # Запустить селектор (опционально)
```

### Остановка всей системы:
```bash
pkill -f "python main.py"       # Остановить ComfyUI
pkill -f "serve_selector.py"    # Остановить селектор
```

### Проверка статуса:
```bash
ps aux | grep "python main.py"  # Процессы ComfyUI
nvidia-smi                       # Нагрузка GPU
```

## 💡 Советы по использованию:

1. **Всегда проверяйте статус GPU** перед отправкой задач
2. **Используйте разные вкладки** для каждого GPU
3. **Мониторьте VRAM** - каждая LatentSync задача использует ~8-12GB
4. **Оптимальная стратегия:** 
   - Короткие видео (до 30 сек) → можно 2 задачи параллельно
   - Длинные видео (1+ минута) → лучше по одной задаче

## 📈 Результаты тестирования:

**Тестовая нагрузка:** 2 видео по 15 секунд каждое
- **Последовательно (1 GPU):** ~4 минуты
- **Параллельно (2 GPU):** ~2 минуты  
- **Экономия времени:** 50%
