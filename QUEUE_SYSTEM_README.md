# ComfyUI Queue System

Система автоматического управления очередью обработки видео для ComfyUI с учетом доступной GPU памяти.

## Компоненты системы

1. **gpu_monitor.py** - Мониторинг использования GPU памяти
2. **queue_manager.py** - Менеджер очереди задач
3. **queue_api.py** - REST API для управления очередью
4. **submit_video_batch.py** - Helper для массовой отправки видео
5. **start_queue_system.sh** - Скрипт запуска всей системы

## Запуск системы

```bash
cd /home/administrator/ComfyUI
./start_queue_system.sh
```

После запуска доступны:
- **ComfyUI**: http://localhost:8188
- **Queue Monitor Web UI**: http://localhost:5000  
- **Queue API**: http://localhost:5000/api/

## Использование

### 1. Через веб-интерфейс
Откройте http://localhost:5000 для мониторинга очереди в реальном времени.

### 2. Через API

#### Добавить задачу:
```bash
curl -X POST http://localhost:5000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "input_video": "/path/to/input.mp4",
    "output_video": "/path/to/output.mp4",
    "workflow": {...workflow_json...},
    "priority": 0
  }'
```

#### Проверить статус очереди:
```bash
curl http://localhost:5000/api/status
```

#### Проверить статус конкретной задачи:
```bash
curl http://localhost:5000/api/tasks/TASK_ID
```

### 3. Массовая отправка видео

```bash
./submit_video_batch.py \
  --workflow example_workflow.json \
  --input-pattern "/path/to/videos/*.mp4" \
  --output-dir "/path/to/processed_videos/" \
  --priority 1
```

## Параметры настройки

### В queue_manager.py:
- `memory_per_video_gb` - Примерное потребление памяти на одно видео (по умолчанию 6GB)
- `safety_margin` - Коэффициент безопасности использования памяти (по умолчанию 0.8 = 80%)

### В gpu_monitor.py:
Можно настроить пороги использования памяти для определения доступных слотов.

## Логика работы

1. **Автоматический расчет слотов**: Система автоматически определяет, сколько видео можно обрабатывать одновременно, основываясь на доступной GPU памяти.

2. **Приоритетная очередь**: Задачи с более высоким приоритетом обрабатываются первыми.

3. **Мониторинг завершения**: Система отслеживает завершение задач через ComfyUI API и автоматически запускает следующие задачи из очереди.

4. **Веб-мониторинг**: Реальное время отслеживания статуса очереди, использования GPU памяти и прогресса выполнения задач.

## Статусы задач

- `pending` - Задача в очереди на выполнение
- `running` - Задача выполняется  
- `completed` - Задача завершена успешно
- `failed` - Задача завершилась с ошибкой
- `cancelled` - Задача отменена

## Мониторинг

Система автоматически:
- Отслеживает использование GPU памяти
- Рассчитывает количество доступных слотов
- Запускает новые задачи по мере освобождения ресурсов
- Предоставляет веб-интерфейс для мониторинга

## Решение исходной проблемы

Теперь вы можете:
1. Отправить любое количество видео в очередь
2. Система автоматически определит, сколько видео может обрабатываться одновременно (в вашем случае ~6 видео)
3. Остальные видео встанут в очередь и будут запускаться автоматически по мере завершения текущих задач
4. Никаких ошибок "tensor size mismatch" - каждое видео обрабатывается отдельно

Больше никаких ручных запусков - просто загружайте видео в очередь!
