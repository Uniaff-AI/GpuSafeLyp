# Добавлено отображение примерного времени выполнения задач

Дата: Wed Oct  1 01:20:14 UTC 2025

## Сделанные изменения:

1. **Backup файла:** Создан `index.html.backup_before_estimated_time`

2. **Функция updateTask():**
   - Добавлен расчет примерного общего времени выполнения
   - Формула: длина_видео * 18 секунд
   - Сохраняется в `task.estimated_total_time`

3. **Отображение времени в интерфейсе:**
   - ⏱️ **Общее примерное время:** показывается в формате "~Xm Ys total"
   - ⏳ **Оставшееся время:** показывается в формате "Xs remaining" (во время выполнения)

## Логика отображения:
- При создании задачи рассчитывается общее примерное время
- Во время выполнения показывается и общее время, и оставшееся
- После завершения остается только общее примерное время

## Frontend обновлен:
- Порт 3001 - обновлен и перезапущен
- Backend работает на порту 8000

Теперь пользователи видят примерное время выполнения каждой задачи на основе длительности видео.
