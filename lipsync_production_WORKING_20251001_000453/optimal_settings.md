# 🎯 ОПТИМАЛЬНЫЕ НАСТРОЙКИ LIPSYNC СИСТЕМЫ

## Рекомендованные параметры (на основе тестирования):

### 🧬 SEED (Зерно случайности):
- **Для стабильности**: 42, 123, 777, 1337
- **Для экспериментов**: любое число 100-9999  
- **Избегать**: очень большие числа (>100000)
- **Влияние**: Контролирует детерминированность нейросети, микровыражения лица

### 🎭 LIPS_EXPRESSION (Интенсивность синхронизации):
- **0.8-1.0**: Портреты крупным планом, минимум искажений
- **1.0-1.3**: Золотая середина для большинства случаев  
- **1.5**: Текущая настройка (подходит для средних планов)
- **>1.5**: Риск переобработки и плывущих масок

### ⚙️ ТЕХНИЧЕСКИЕ ПАРАМЕТРЫ:
- **trim_to_audio**: true ✅ (синхронизирует длительность)
- **save_output**: true ✅ (автоматическое сохранение)

## 🐛 Известные проблемы:
- **Сервер 8189**: Проблемы с детекцией лица (CUDA device 1)
- **Плывущая маска**: Понизить lips_expression до 1.0-1.2
- **Искажения**: lips_expression < 1.3 для детализированных лиц

## 🎯 Рекомендации для качественных результатов:
- seed: 777 или 1337
- lips_expression: 1.0-1.3
- trim_to_audio: true
- save_output: true
